# 出毛日记 · Chumao Diary

> 面向**福瑞 / 兽装（Furry / Fursuit）爱好者**的出毛记录与地点发现工具 —— 微信小程序。

记录每一次「出毛」的足迹，查找适合拍摄的场地，看一眼今天适不适合穿毛出门。

---

## 一、这是什么项目

**出毛日记**是一款以地图为核心的信息查询与记录工具，服务于兽装爱好者（圈内称「出毛」= 穿着兽装外出活动）的日常需求。

| 项目 | 说明 |
|---|---|
| 定位 | 出毛足迹记录 + 出毛场地发现 + 出毛适宜度参考 |
| 目标用户 | 福瑞 / 兽装爱好者及其社群 |
| 解决什么问题 | ① 出毛地点散落在聊天记录里，没有沉淀 ② 不知道今天天气适不适合穿毛外出 ③ 找不到场地周边的更衣、停车、补给等配套设施 |
| 内容形态 | 地点库由运营方录入；用户足迹只存本机，不做公开传播 |

---

## 二、核心功能

### 三个主页面（tabBar）

| 页面 | 功能 |
|---|---|
| **发现** | 地图浏览收录地点，支持城市切换与视角快切（精选 / 全部 / 我出过毛 / 我收藏的）；点击地图即落针识别周边 POI；顶部为**出毛适宜度**看板 |
| **足迹** | 记录个人出毛足迹（时间、地点、照片、备注），生成成就徽章墙与足迹地图，可导出分享海报 |
| **我的** | 个人资料、收藏地点、设置入口 |

### 功能亮点

| 功能 | 说明 |
|---|---|
| **出毛适宜度** | 纯函数引擎 `utils/furIndex.js`：基于温度、降水、风力、紫外线等因子计算「今天适不适合出毛」。>35℃ / <0℃ / 雨雪雷雾霾为硬阻断，缺紫外线数据时自动降级为 4 因子 |
| **足迹成就地图** | 足迹落点 + 47 城徽章墙 + 里程碑成就，支持缩放拖动 |
| **兽聚管理** | 用户在本机自建兽聚（名称 / 城市 / 日期 / 照片 / 参与人数），地图上生成兽聚针 |
| **找场地** | 双模式：带地点 id = 查此地周边配套；不带 id = 按需求（洗手间 / 更衣 / 停车 / 补给）找场地 |
| **分享海报** | 足迹海报含全国地图卡、成就徽章、小程序码，全部内容程序化生成 |
| **收藏合集与路线** | 把收藏地点整理成合集，对合集内地点规划驾车 / 步行 / 骑行路线 |
| **季节推荐 / 地点榜** | 按当季特征推荐，按收藏数排行 |
| **地点反馈** | 用户单向提交纠错或推荐（仅运营方可见，不进公开地点库） |

## 四、技术栈

| 层 | 选型 |
|---|---|
| 小程序端 | 原生微信小程序（WXML / WXSS / JS），零 npm 运行时依赖 |
| 后端 | 微信云开发云函数（Node.js），50+ 个云函数 |
| 数据库 | 云开发文档型数据库（云数据库集合） |
| 地图 | 腾讯位置服务（LBS）—— 逆地址解析、POI 检索、路线规划、静态地图 |
| 天气 | 公开气象数据（温度 / 降水 / 风力 / 紫外线） |
| 测试 | 自研 Node 脚本 + `miniprogram-automator` 端到端验证（40+ 项静态与运行时断言） |
| 设计 | 主色琥珀金 `#D4890E`；字体站酷快乐体 + Noto Sans SC |

**共享模块机制**：`cloudfunctions-shared/` 为母本，通过 `scripts/sync-shared.js` 分发到各云函数副本，`--check` 模式保证副本与母本一致。

## 八、本地运行

1. 用**微信开发者工具**打开本目录（`project.config.json` 已配置）
2. 将 `project.config.json` 中的 `appid` 替换为你自己的小程序 AppID
3. 在云开发控制台创建环境，并把环境 ID 配到 `app.js` 的 `env` 字段
4. 地图 / 天气相关云函数依赖环境变量 `TENCENT_MAP_KEY`（腾讯位置服务 Key），需自行申请并配置
5. 部署云函数：开发者工具中右键 `cloudfunctions/` 下各函数 → 上传并部署（云端安装依赖）

> 提示：地图静态图与审图号展示需在 `utils/mapView.js` 的 `MAP_APPROVAL_NUMBER` 填入已获批的审图号。

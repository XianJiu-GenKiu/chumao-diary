# 出毛地图 - uni-app 项目

探索与发现 - 地图位置标注分享平台

## 快速开始（HBuilderX）

### 1. 下载安装 HBuilderX

下载地址：https://www.dcloud.io/hbuilderx.html

推荐下载 **App 开发版**（包含小程序开发工具）

### 2. 导入项目

1. 打开 HBuilderX
2. 文件 → 打开目录 → 选择 `d:\出毛地图`
3. 项目会自动识别为 uni-app 项目

### 3. 运行到微信开发者工具

1. 点击工具栏的「运行」按钮
2. 选择「运行到小程序模拟器」→「微信开发者工具」
3. 首次运行会提示配置微信开发者工具路径
4. 配置完成后会自动打开微信开发者工具并编译运行

### 4. 也可以运行到其他平台

- 运行到 QQ 小程序模拟器
- 运行到浏览器
- 运行到手机模拟器

## 项目结构

```
d:\出毛地图/
├── pages/           # 页面目录
│   ├── index/       # 地图首页
│   ├── share/       # 共享群组
│   ├── message/     # 消息中心
│   ├── profile/     # 个人中心
│   ├── annotation/  # 标注相关
│   ├── group/       # 群组相关
│   ├── settings/    # 设置
│   └── user/        # 用户页面
├── static/          # 静态资源
├── styles/          # 全局样式
├── App.vue          # 应用入口
├── main.js          # 主入口文件
├── manifest.json    # 应用配置
├── pages.json       # 页面路由配置
└── uni.scss         # 全局变量
```

## 主要功能

- ✅ 地图标注 - 随时随地对喜欢的地点进行标注分享
- ✅ 群组共享 - 创建或加入群组，查看所有成员的标注
- ✅ 评分评论 - 对标注的地点进行评分和评论
- ✅ 自定义分类 - 支持按美食、风景、娱乐等分类管理
- ✅ 跨平台 - 支持微信小程序和 QQ 小程序

## 注意事项

1. 首次运行需要在微信开发者工具中点击「编译」
2. 如需修改 AppID，在 `manifest.json` → 微信小程序配置 中修改
3. 地图功能需要配置腾讯地图密钥
4. 发布前请在微信公众平台配置域名白名单
